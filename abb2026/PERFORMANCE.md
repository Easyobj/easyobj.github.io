# V4 Phase 1 性能优化

本阶段只做性能基础设施，不改变互动题型逻辑。

## 已实施
- 首屏 Loading 只等待关键首页资源；互动页不再首屏全量预加载。
- 其余首页资源在首屏完成后通过 requestIdleCallback/延时后台预热。
- 互动页按点击场景异步加载并 decode；返回首页后移除当前互动大图 DOM src。
- 首页场景进入视口才执行入场动画；持续微动离开视口后暂停。
- 移除大图入场 blur、点击 brightness、全局永久 will-change。
- 首页背景及场景生产图按 750px H5 的实际显示尺寸重新缩放。
- 当前过渡期互动整图由 1563px 宽缩到 1125px 宽；下一阶段将改成 HTML/CSS + 局部素材。

## 理论 RGBA 解码内存变化（所列生产图）
- 优化前约：168.7 MB
- 优化后约：75.8 MB
- 理论减少约：55.1%

注意：浏览器实际内存还受纹理缓存、WebView、设备 DPR 与资源生命周期影响。

## 下一阶段
把 01～05 互动页从“PSD 整图 + HTML 覆盖”改为“HTML/CSS 精确还原 + PSD 局部装饰素材”，进一步降低内存并解决 UI 重复问题。

## 背景图 1125px 调整
- 首页背景 `layer_1.webp`：1500×2665 → 1125×1999
- 理论 RGBA 解码内存：15.2 MB → 8.6 MB
- 其余首页场景图与交互逻辑保持不变。


## V4 Phase 3：互动页去整图
- 01～05 不再加载 1563px 宽的互动整图。
- 互动页改为 HTML/CSS + 首页已有透明场景素材组合。
- 引入 ABBvoice CNSG Regular/Bold 本地 WOFF2，降低字体差异。
- 删除 `assets/interactions/scene-01~05.webp`，减少下载、解码和 GPU 纹理占用。
- 页面背景复用已优化到 1125px 的首页背景。
- 题目、按钮、选项、判断框、文本输入全部为真实 DOM，可直接接后端/埋点。


## V5.0 验证说明

- 互动页不再使用固定 PSD 高度，内容增长时由文档自然撑开，避免高屏底部空白和小屏裁切。
- 关键图片预加载会区分成功与失败；失败时给出可重试提示。
- Service Worker 字体缓存升级为 `abb-fonts-v2`，并在安装后立即接管新版本。
- 当前两个完整 WOFF2 文件仍约 7 MB。字体子集化需要品牌方确认字符范围和字体交付方式，本次未擅自生成替代字体文件。
