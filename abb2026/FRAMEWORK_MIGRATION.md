# ThinkPHP 复用与数据库隔离说明

版本：V5.8.0 / `5.8.0-thinkphp-3.2.3`，2026-10-02。

## 已实现

入口 `index.php` 真正加载去年项目的 ThinkPHP 3.2.3 内核，而不是仅复用目录名称。活动由 `Other/Index` 控制器和 PHP 视图渲染，微信授权由 `Other/Auth` 处理，后台由 `Admin/Index` 处理。答题、抽奖使用普通表单和服务器会话；原有 PDO 事务、参数化查询、一次抽奖约束、CSRF 与核销审计保留在 `Application/Common/Service/`。

生产入口：`index.php`；后台：`index.php?m=Admin&c=Index&a=index`；授权回调：`index.php?m=Other&c=Auth&a=callback`。旧 `api/auth/` 与 `api/admin/` 地址仅保留兼容入口。健康检查 JSON 仍用于运维，不是前端业务渲染架构。

仅允许四个明确的控制器动作；拒绝 POST 覆盖路由、PATH_INFO、任意模块和继承的 `display/assign` 等动作。关闭框架调试、源码目录直访、屏幕异常详情和页面缓存。PHP 8 兼容改动及许可证详见 `ThinkPHP/ABB_COMPATIBILITY.md`。

## 今年数据库和真实配置

活动方选择同一服务器、数据库账号及公众号，新库固定为 `abb20260919game`。初始化工具只操作该库，不连接或改写 `abb20250919game`，已有非空 `abb20260919game` 也不会被重新初始化。新库使用今年的用户、答案、奖品、抽奖及管理表，不搬运去年的业务记录。

凭据导入工具从旧私密配置读取真实值，生成独立受限文件，不输出密码/密钥、不覆盖已有文件。生产通过 `ABB_CONFIG_FILE` 指向 Web 根之外的文件；本地配置保持被忽略。私密值不进入 ThinkPHP 编译配置缓存或 Pages。

复用账号保留原数据库权限，并不构成最小权限隔离。旧凭据的历史暴露风险仍存在；本次遵从沿用决定，不擅自轮换或影响旧业务。

## 验证与边界

本地使用 PHP 8.5 和 MariaDB 独立临时数据库完成业务与 HTTP 回归，包括 CSRF、路由限制、PHP 模板、后台锁定、CSV 公式防护、并发重复抽奖、库存扣减一次、核销一次、非微信门禁与 OAuth state 拒绝检查。测试数据库与账号运行后清理，未使用生产奖池或真实微信接口。

框架 PHP 文件通过语法检查，但并不代表所有历史可选驱动均得到业务验证；本项目不启用这些驱动。PHP 兼容变更不等于对历史框架做了完整安全审计。

远端建库、正式域名配置及真实微信授权必须在提供 SSH 连接信息、活动域名和活动时间后完成。Pages 仅展示同一版本的静态视图，不能证明正式后端已部署。
