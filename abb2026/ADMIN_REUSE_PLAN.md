# 后台复用计划与第一阶段说明（2026-10-05）

原则：沿用去年成熟的通用功能、导航结构和操作习惯；数据访问适配今年独立库，保留今年安全实现。积分、概率、核销等活动定制单独处理。不导入去年用户或账号数据，不复制旧 MD5、任意上传、全 Runtime 清理和任意扫码跳转代码。

## 分阶段推进

| 阶段 | 范围 | 状态 |
| --- | --- | --- |
| 1 · 导航与布局 | 深色左菜单、顶部账号/退出、面包屑、独立 PHP 内容页；手机折叠菜单 | V5.9.16 发布；后台八模块及手机导航，按正式部署记录验收 |
| 2 · 通用账号管理 | 网页新增、编辑、停用、重置密码、本人改密码；权限边界、旧会话失效、最后运营账号保护、审计 | V5.9.18 已实现，网页操作与权限验证见正式部署记录 |
| 3 · 查询与分页 | 参与者、六站答题明细、全部中奖/领取记录；搜索、分页、详情及按需导出 | V5.9.18 已实现，支持 20/50/100 条分页、关键词/日期/状态筛选及六站详情 |
| 4 · 今年业务整理 | 活动日期、七奖品/日限额、实际余量加权、扫码本人核销、风险与审计页面整合和最终回归 | 本轮仅拆页，不改业务规则；后续继续完善 |

每阶段按 AGENTS.md 同步源码、纯 FTP 包和 Pages，提交/推送后验证线上版本，再提供两个提交哈希和 URL。Pages 不运行 PHP，不能替代服务器后台或微信验收。

## 第一阶段：八个现有模块

统一入口：`index.php?m=Admin&c=Index&a=index`。登录后运营员默认进入首页统计，核验员默认进入现场核验。新增 `page` 为固定白名单，不将请求参数转换为模板路径。

| page | 菜单 | 权限/内容 |
| --- | --- | --- |
| dashboard | 首页统计 | 运营员；参与、通关、抽奖、核销计数、活动告警与快捷入口 |
| activity | 活动设置 | 运营员；日期、暂停/恢复抽奖 |
| prizes | 奖品管理 | 运营员；七奖品方案、库存及日配额、既有旧奖品清理 |
| draws | 中奖记录 | 运营员；完整分页、筛选及领取状态 |
| answers | 开放题答案 | 运营员；六站记录筛选分页及开放题 CSV，不含 OpenID |
| redemption | 现场核验 | 运营员/核验员；单框手输二码合一核销码、人工核对、一次性核销 |
| risk | 风险审核 | 运营员；既有线索与人工结论，不自动拒奖 |
| audit | 操作日志 | 运营员；完整审计分页与搜索 |

菜单按服务端角色生成；核验员直接访问运营页面返回 403，未知/数组/路径式 page 返回 404。跨模块表单返回 422，不能在另一页面隐蔽执行。原不带 page 的旧地址及表单仍兼容，按已授权动作显示所属模块。退出仍为带 CSRF 的 POST，成功变更后跳回对应模块。

沿用去年 `Public/nav.html` / `top.html` 的左侧导航、顶部账号和单模块内容结构，参考深色侧栏与浅色工作区颜色；不用旧 jQuery/iframe/插件组合。现有 ThinkPHP 与 PHP 模板继续使用。年度业务服务、数据库结构、管理员密码、微信密钥和前端 PSD 布局不变，仅更新发布版本。微信扫一扫已暂停，现场核验保留单框手输流程。

## 预览与验收

- `admin-preview.html` 从同一 PHP 模板离线生成，仅展示首页布局。统计为“—”，无登录账号、CSRF、表单、真实数据和可执行业务；菜单标记为仅展示，不模拟其他模块结果。
- FTP 包不包含静态预览、文档、测试或私密配置。更新时保留服务器的 config.local.php 与 Runtime，预创建 PHP 用户可写的版本缓存目录。
- 隔离数据库回归覆盖八模块、七个越权 GET、伪造 POST、路径/脚本/数组参数、跨模块表单、旧书签，以及库存、领取时限、一次性核销、CSRF、会话和权限。隔离测试运营/核验员在 375/390/1280px 浏览器核对菜单、页面、查询与无横向页面溢出；截图仅本地保留。
- 公众号扫一扫原有 IP 白名单阻塞不属于布局修改，本阶段不修改公众号配置、不声称摄像头已验收。正式服务器验证应只读访问模块与登录/退出，不动活动开关、奖品、中奖或领取记录。

去年功能证据与未迁移项见 [LAST_YEAR_BACKEND_REVIEW.md](LAST_YEAR_BACKEND_REVIEW.md)。

## V5.9.18 网页管理与查询

新增参与者、账号管理和本人改密码菜单。账号管理仅运营员可用，核验员可改本人密码；所有敏感账号写入验证操作者密码，事务内串行校验最后运营员并写审计，过期表单被拒绝。角色、用户名或密码变化撤销旧会话，修改本人后重新登录。无硬删除账号，不在网页或审计中输出密码/密码哈希。

参与者可按昵称/编号、注册日期及通关状态筛选；答题可按昵称/编号/回答内容、日期、题目及结果筛选；中奖可按昵称/编号、礼品/兑奖码、日期及领取状态筛选；风险、审计和账号列表也有完整分页。分页保留筛选条件，支持上一页/下一页、首末页和页码跳转。用户详情显示六站当前答案、结果、累计尝试次数及中奖/核销信息；数据库只保存当前答案，不伪造历史逐次作答记录。

## V5.9.19 已发布补充

新增测试数据清理菜单：正式发布时间之前、允许测试且暂停抽奖时可使用，先自动备份并核对快照，操作需确认全部测试用户和管理员密码。到正式发布时间自动关闭清理。日期升级详见 `TEST_DATA_RESET.md`。现场核验改为四位数字核销码，当天本人领取，无两小时限制或客户端倒计时。
